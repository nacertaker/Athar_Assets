# Athar Assets

ملفات تطبيق «أثر» (خلفيات الفيديو). لا تحتوي هذه الصفحة على كود؛ الملفات نفسها تُرفع في **Releases**.

## الخلفيات

تُرفع في إصدار (Release) واحد وسمُه `backgrounds`، كملفين بالاسم نفسه:

| الملف | ما هو |
| --- | --- |
| `الاسم.mp4` | فيديو الخلفية (بلا صوت، عمودي 9:16، مدته بين 2 و90 ثانية) |
| `الاسم.jpg` | صورة المعاينة التي تظهر في شبكة الخلفيات |

- اسم الملف هو اسم الخلفية وهو الاسم الذي يظهر في التطبيق، ولا يُغيَّر بعد النشر.
- التطبيق يقرأ قائمة ملفات الإصدار ويعرض أي خلفية جديدة مباشرة دون تحديث.
